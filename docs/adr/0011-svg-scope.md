# 0011. Область поддержки SVG в MVP

- **Статус:** Accepted
- **Дата:** 2026-11-04

## Контекст

SVG — большой формат: фигуры, текст, растр, градиенты, clipPath/mask/filter, обводки, CSS, сriptы, внешние ссылки.
Поддержать всё сразу невозможно; при этом молча «потерять» часть картинки — худший сценарий для пользователя.

## Решение

**Поддерживается (геометрия):**

- `path` — все команды, включая `A/a` (дуги), `S/s`, `T/t`; неявные повторы `M`; `Z/z`.
- `rect` (включая `rx/ry`), `circle`, `ellipse`, `polygon`, `polyline`, `line`.
- `use` — разрешается по `href`/`xlink:href` в пределах документа, с `x/y/width/height` и трансформом.
- `<g>` — любая вложенность, `transform` (matrix/translate/scale/rotate/skewX/skewY), вложенные трансформы.
- `fill` как сплошной цвет (hex, `rgb()`, имена цветов, `currentColor`), `fill-rule` (nonzero/evenodd),
  наследование через `<g>`, presentation attributes и `style`.
- `stroke` → отдельная область (см. ADR-0014): `stroke-width`, `stroke-linecap` (butt/round/square),
  цвет обводки; обводка становится отдельным элементом дерева со своими настройками.
- `mask` на фигуре — по яркости содержимого (белое = видно, чёрное = скрыть), см. ADR-0015.
- `display:none` / `visibility:hidden` — элемент считается скрытым (по умолчанию выключен).

**Игнорируется с предупреждением:**

- `stroke-dasharray` (пунктир) — обводка рисуется сплошной;
- `stroke-linejoin: miter/bevel` — стыки скругляются (безопасное приближение);
- `mask` на группе и градиентные/полупрозрачные маски;
- `text`/`tspan` (шрифты и глифы вне области);
- `image` (растр);
- `clipPath`, `filter`, `pattern`, `linearGradient`/`radialGradient` как геометрия
  (элемент берётся по `fill`-цвету, если геометрия понятна, иначе — предупреждение);
- `opacity`/`fill-opacity` — учитываются только как признак прозрачности (`opacity < 0.5` → предупреждение),
  на геометрию не влияют.

**Безопасность:** `script`, `foreignObject`, `on*`-атрибуты, внешние `href` и `@import` вырезаются при санитизации.

Каждое игнорирование попадает в `warnings` с `nodeId` и текстом; в UI — панель предупреждений со ссылками
на узлы дерева.

## Последствия

- Пользователь видит, что именно не попало в модель, а не догадывается.
- Проверка: фикстуры с `text`, `stroke`, `clipPath` должны давать предупреждения в тестах.
- Расширение области — по одной фиче за раз, с тестом и записью в ADR/PLAN.

## Когда пересматривать

Когда появится реальная потребность: текст (преобразование глифов через opentype.js), `mask`/`clipPath`
(2D-вычитание у нас уже есть — вопрос в семантике масок) или пунктир.
