# 0016. Рендеринг предпросмотра: плоские нормали и пресеты вида

- **Статус:** Accepted
- **Дата:** 2026-11-04

## Контекст

На высоких элементах (десятки мм) в 3D были видны треугольники: на длинных боковых стенках появлялся
градиент, а диагональ разбиения каждой грани читалась как артефакт. Причина — `computeVertexNormals()`:
нормали усредняются в общих вершинах, поэтому на стыке стены с верхней/нижней гранью (90°) нормаль
«размазывается», и линейная интерполяция по треугольнику даёт разную заливку. Чем длиннее стена в пикселях,
тем заметнее.

Плюс не хватало управления видом: в 2D нельзя было отключить полупрозрачность, а в 3D — выбрать свет/материал.

## Рассмотренные варианты нормалей

1. **Оставить сглаженные** — артефакты сохраняются, лечится только «нормальным» разбиением с весами.
2. **Разбивать вершины по группам сглаживания** (свои нормали для каждой грани) — это и есть плоские нормали,
   но с ручной работой по сварке вершин; та же визуальная цена.
3. **`flatShading: true`** — нормаль считается на треугольник. Плоские грани становятся однородными,
   диагональ исчезает. Цена: фаски (ступени 0.05 мм) и скругления показываются гранями.

## Решение

- Все материалы — `MeshStandardMaterial` с `flatShading: true`. Для печатной модели это честно: пользователь
  видит реальные грани, а не сглаженную интерполяцию.
- Материалы различаются шероховатостью: **матовый** `roughness 0.85`, **глянцевый** `roughness 0.12`
  (`metalness` ≈ 0, чтобы цвет не темнел без environment map).
- Пресеты освещения (`studio` | `top` | `flat`):
  - **Студийное** — фоновый + заполняющий + ключевой свет справа-сверху: лучше всего читается рельеф;
  - **Сверху** — почти вертикальный ключевой свет и слабое заполнение: похоже на превью слайсера;
  - **Плоское** — только ambient, без направленного света: ровная заливка цветом для проверки силуэтов.
- Настройки вида живут в `GlobalSettings.view` (`opaque2d`, `lighting`, `material`), сохраняются в
  `.svg23d.json` и **не вызывают пересчёт геометрии** (отдельное действие `updateView` в сторе).
- В 2D `opaque2d` убирает полупрозрачность невыделенных элементов.

## Последствия

- Артефакты треугольников исчезли на любой высоте (проверено на 30-мм модели).
- Старые файлы проектов без блока `view` при загрузке получают значения по умолчанию (`mergeGlobal`).
- Смена материала/света мгновенная: обновляются только свойства материалов и интенсивности ламп.
- Плоское освещение специально «убивает» объём — это режим проверки контуров, а не для презентации.

## Когда пересматривать

- Понадобится «красивая» картинка с отражениями — добавить environment map (`RoomEnvironment`) для глянца.
- Если фаски станут крупными (1–2 мм) и ступени начнут мешать — перейти на точную лофт-фаску (ADR-0007)
  вместо повышения качества нормалей.
