# 0007. Фаски: 45°, размер в мм, ступенчатая тесселяция

- **Статус:** Accepted
- **Дата:** 2026-11-04

## Контекст

Нужно снимать фаски сверху и снизу элемента. Manifold не умеет fillet/chamfer: у него есть 2D-`offset`,
`extrude`, булевы операции и `hull`, но нет операции «скосить ребро».

Физический смысл 45°-фаски размера `c`: верхняя грань детали уменьшена на `c` по контуру, а боковая стенка
переходит в неё наклонной поверхностью высотой `c` (фронт смещения движется внутрь со скоростью 1:1 по Z).

## Рассмотренные варианты

1. **Ступенчатая тесселяция**: разрезать зону фаски на `N` горизонтальных слоёв, в каждом слой — `offset(-delta)`
   от контура, объединить. Реализуется только существующими операциями, устойчиво, предсказуемо.
   Минус: поверхность ступенчатая, шаг `c/N`.
2. **Точный лофт-меш**: построить боковую поверхность как набор квадов между контуром (у основания фаски) и
   контуром, смещённым внутрь (на верхней грани), плюс крышки. Геометрически точная 45°.
   Минус: нужна взаимно-однозначная корреспонденция вершин между двумя контурами. `offset` меняет топологию
   (добавляет/удаляет вершины, может разбивать контур на несколько), поэтому наивное сопоставление по индексу
   даёт самопересекающийся меш. Нужен надёжный алгоритм сопоставления и валидация — это отдельная нетривиальная задача.
3. **Использовать OCCT (Replicad) только для фасок** — точный `chamfer` на рёбрах, но тянет второй тяжёлый WASM
   и второй конвейер данных (смешивание mesh и B-Rep).

## Решение

Вариант 1 на MVP.

- Параметры: `chamferTop` и `chamferBottom` в мм, угол фиксирован 45° (`радиальное смещение = высота`).
- Тесселяция: шаг по умолчанию `0.05 мм` (`CHAMFER_STEP_MM`), число слоёв `max(1, ceil(c / 0.05))`, ограничено
  сверху (`MAX_CHAMFER_LAYERS = 40`) для защиты от гигантских значений.
- Реализация: `chamferedExtrude(cs, zFrom, zTo, bot, top)` возвращает `Manifold` — конкатенация
  призматических слоёв с прогрессивным `offset(-delta)`.
- Для резака-призрака (ADR-0005) применяется та же функция с тем же `c`, поэтому гнездо повторяет фаску детали.

Почему шаг 0.05 мм: типичная высота слоя FDM 0.08–0.2 мм, ступень 0.05 мм не видна на печати и не влияет
на посадку. Объём при этом отклоняется от идеального меньше чем на 0.2 %.

## Последствия

- Устойчиво: только `offset` + `extrude` + `add`, никаких ручных мешей.
- Стоимость: `N` лишних операций offset/extrude на каждый лист с фаской; при `c = 1 мм` это 20 слоёв.
  Кэшируется по ключу «лист + параметры».
- `chamfer` не может быть больше половины высоты элемента — валидация в UI с автокоррекцией и предупреждением.
- Внешний вид: ступеньки видны в 3D-превью при сильном приближении (сглаживание через flat shading не применяем,
  чтобы пользователь видел реальную геометрию).

## Когда пересматривать

Если понадобится CAD-точная фаска или скругление (fillet) — реализовать лофт-меш с сопоставлением вершин
по проекции на исходный контур, с валидацией через `Manifold` (если меш невалиден — откат на ступенчатый вариант).
