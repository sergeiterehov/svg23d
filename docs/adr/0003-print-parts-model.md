# 0003. Модель сборки: набор отдельных печатных деталей с гнёздами

- **Статус:** Accepted
- **Дата:** 2026-11-04

## Контекст

Плоское SVG превращается в многослойный рельеф: небо, солнце, холм, дерево. Слои пересекаются по XY и по Z.
Цель — печатать детали и **собирать** их после печати: снимать слой за слоем, вставляя верхние элементы
в гнёзда нижних. Допуск нужен именно для того, чтобы детали физически входили друг в друга.

Возможные трактовки результата:

- одна совмещённая деталь (всё сплавлено, печать «на месте», цвет — мультиматериалом);
- набор отдельных деталей, каждая печатается отдельно и вставляется в нижнюю;
- оба режима.

## Рассмотренные варианты

1. **Одна деталь** — просто union всех элементов. Плюс: одна печать, минимум операций.
   Минус: невозможно собрать из разных материалов/цветов после печати, допуск не нужен вовсе.
2. **Набор отдельных деталей** — каждая деталь печатается отдельно, нижние получают гнездо с зазором.
   Плюс: реальная сборка, разные материалы, крупные детали печатаются по одной.
   Минус: больше объектов, нужна раскладка на столе, сложнее булевы операции.
3. **Оба режима переключателем** — гибко, но удваивает количество сценариев в UI и тестах.

## Решение

Вариант 2. Каждый лист SVG принадлежит **детали** (`partId`). Деталь = объединение своих листьев.
Признак `isPart` на узле означает «здесь начинается новая печатная деталь»; по умолчанию деталями становятся
дети корневого `<svg>`, а если такой ребёнок один — его дети.

Правила:

- **Внутри** одной детали пересечения листьев просто объединяются (union), без вырезания: это одна печатная деталь.
- **Между** деталями более высокий лист вычитает свой объём из более низкого с зазором.
- Экспорт — мультиобъектный 3MF: объект на деталь, координаты исходные (раскладку делает Bambu Studio).

## Последствия

- Режим «одна деталь» остаётся доступен без отдельного кода: достаточно пометить всё как одну деталь.
- Появляется понятие «деталь» в UI (бейджи в дереве, список деталей, статистика по каждой).
- 3MF обязан поддерживать несколько объектов — это фактически обязательное требование к экспорту.

## Когда пересматривать

Если понадобится печать «на месте» с мультиматериалом как первый класс — добавить автогруппировку в одну деталь
и превью разрезов, не меняя ядро.
