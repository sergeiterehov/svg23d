# 0020. Стрелки высоты на самой 3D-модели

- **Статус:** Accepted
- **Дата:** 2026-11-04

## Контекст

Высоту «от»/«до» приходилось править через инспектор: найти элемент в дереве, найти поле, ввести
число. Для подгонки «на глаз» по модели это медленно — глазами смотришь в 3D, а руки идут в панель.

Первая попытка — HTML-кнопки со стрелками поверх превью — оказалась «мимо»: пользователь ждёт стрелки
на модели, а не ещё одну панель.

## Решение

- В сцену добавляются два 3D-указателя (`src/viewer/heightHandles.ts`): верхний — на верхней границе
  выделения, нижний — на нижней. Они образуют вертикальную «ось высоты» выбранного элемента.
- Стрелки видны **только при выделении** и стоят на границах выбранного: верхняя — на максимуме
  «до» выделения, нижняя — на минимуме «от» (при мультивыборе берутся max/min по выбору). Ничего не
  выбрано — стрелок нет. Положение берётся из **настроек выделения**, а не из габаритов меша: так
  значения совпадают с тем, что показывает инспектор, даже если элемент вырезан из модели.
- Указатели **тянут**, а не нажимают: захват стрелки мышью переводит её в режим перетаскивания
  (орбита на это время отключается), вертикальное движение курсора переводится в миллиметры
  (`мм/пиксель` считается по активной камере — так и для перспективы, и для ортогонали) и
  округляется до шага `HEIGHT_STEP_MM` = 0.5 мм.
- Верхняя стрелка меняет «до», нижняя — «от». Правка идёт через `nudgeHeight` относительными шагами,
  поэтому у мультивыбора каждый элемент сдвигается от своего значения.
- Всё синхронно: `nudgeHeight` обновляет стор → пересборка запускается **без задержки** (`immediate`),
  стрелки переставляются по новому диапазону, поля инспектора показывают новые числа. Отдельного
  визуального смещения стрелки нет, поэтому нет и рассинхрона «стрелка уехала, модель догнала».
- Курсор над стрелкой — `ns-resize`; наведение подсвечивает стрелку. Луч стрелок проверяется **раньше**
  деталей, поэтому захват стрелки не выбирает деталь под ней.
- Размер стрелок пропорционален модели (`max(Ш, В, Г) × 0.22`, в пределах 6…48 мм) — они одинаково
  удобны и на 20-мм, и на 200-мм детали.
- Материал стрелок с `depthTest: false` и `renderOrder: 10`: нижняя стрелка находится под столом, и без
  этого она была бы не видна. Это UI-элемент, а не часть модели, поэтому «просвечивание» сквозь деталь
  здесь уместно.

## Последствия

- XY-центр и размер стрелок обновляются по габаритам модели (`setParts` → `handles.update(bounds)`),
  Z и видимость — по диапазону выделения (`setHeightRange`).
- Пересборка на каждом шаге перетаскивания идёт без дебаунса; лишние задания отсекает механизм
  `jobId` в воркере, а серия шагов сворачивается в один шаг отмены (коалесинг по ключу).
- Правка работает только в 3D; в 2D остаются поля инспектора.
