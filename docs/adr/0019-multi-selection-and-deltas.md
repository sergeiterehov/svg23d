# 0019. Множественный выбор и дельты в числовых полях

- **Статус:** Accepted
- **Дата:** 2026-11-04

## Контекст

Дерево умело выбирать ровно один элемент, а инспектор — редактировать его настройки. Для модели из
десятка деталей это медленно: одинаковые высоту, допуск или фаску приходится выставлять по одной.

Отдельная проблема — правка «на чуть-чуть»: чтобы сдвинуть высоту на 2 мм, нужно в голове сложить
текущее значение и прибавление. Хочется писать `+2`.

При этом поле, которое коммитит на каждый символ, с дельтой конфликтует: набирая `-2`, пользователь
видит, как значение прыгает на `-` (невалидно), потом на `-2`.

## Решение

### Выбор

- `selectedIds: string[]` в сторе. Обычный клик по строке дерева (или по детали в 3D) заменяет выбор,
  ⌘/Ctrl-клик — добавляет/убирает элемент (`toggleSelected`). Клик по пустому месту снимает выбор.
- Превью подсвечивают все выбранные элементы: в 2D — объединение поддеревьев, в 3D —
  `OutlinePass.selectedObjects` со всеми деталями выбора.

### Отображение смешанных значений (инспектор, режим «Выбрано: N»)

| Настройка | Одинаковые значения | Разные значения |
| --- | --- | --- |
| Высота от/до, допуск, фаски | значение в поле | поле пустое, плейсхолдер `12-15` (min-max) |
| «Отдельная деталь», «Скрыть» | переключатель вкл/выкл | промежуточное положение + подпись «разное» |
| Цвет модели | обычный свёрток цвета | чип из двух цветов по диагонали + «разное» |
| Качество кривых | — | настройка проекта, в мультивыбор не входит |

Правка любого поля в мультирежиме применяется ко всем выбранным сразу и **одним шагом отмены**
(`updateSettingsBatch`).

### Дельты и момент применения

- Любое числовое поле принимает `+2`, `-2`, `+0,5` — изменение относительно текущего значения.
  Для мультивыбора дельта считается от значения каждого элемента отдельно.
- Значение без знака — абсолютная установка; пустая строка — сброс к наследуемому.
- Ввод применяется по **Enter или уходу из поля**, а не на каждый символ: так набор `-2` не
  превращается в промежуточное `-`. Escape отменяет ввод, ↑/↓ меняют черновик на шаг поля.
- В подсказках полей дельта не упоминается: «?» объясняет саму настройку, а не способы ввода.

## Последствия

- `NumberField` стал текстовым полем (`type="text"`, `inputMode="decimal"`) с разбором ввода:
  `parseDelta` (знак → дельта) и `parseNumber` (запятая как разделитель тоже принимается).
- Ограничения `min` применяются и к абсолютным значениям, и к результату дельты.
- Число шагов отмены не растёт с размером выбора: пачка правок — одна запись истории.
