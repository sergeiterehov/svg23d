# 0005. Допуск: зазор на сторону, резак = offset(+clearance) с той же фаской

- **Статус:** Accepted
- **Дата:** 2026-11-04

## Контекст

Верхний элемент вырезает в нижнем гнездо, чтобы детали после печати совмещались. Нужен зазор (допуск) —
«2D-аналог ширины обводки, только в 3D вокруг детали». Он должен быть в мм и легко предсказуемым для пользователя.

Два вопроса:

1. Допуск измеряется **на сторону** или как **суммарный** зазор?
2. Как геометрически строить гнездо: вычитать сам твёрдый объём верхнего элемента или его «призрак», расширенный
   в 2D?

## Рассмотренные варианты

1. **Зазор на сторону.** `clearance = 0.1 мм` → отверстие больше детали на `0.2 мм` по любому размеру.
   Совпадает с интуицией «обводка вокруг детали» и с таблицами допусков для FDM.
2. **Суммарный зазор.** `0.2 мм` → отверстие больше на `0.2 мм`. Проще считать общий зазор, но путает:
   пользователь думает «зазор 0.2» и получает 0.1 с каждой стороны.

Для построения гнезда:

- **(a)** вычитать из нижнего листа `solid(верхний лист)`, расширенный в 3D — расширить 3D-меш нельзя без offset 3D.
- **(b)** строить «призрак»: 2D-контуры верхнего листа с `offset(+clearance)`, экструзия в том же z-диапазоне и
  с теми же фасками, что у верхнего листа. Это и есть резак.

## Решение

1. **Допуск — зазор на сторону.** В хранимых данных `clearance` = зазор на сторону. В UI подписан явно:
   «допуск, мм на сторону» + подсказка «отверстие будет больше на 2×».
2. **Резак — «призрак» (b)**: `CrossSection.offset(+clearance)` от контуров верхнего листа, экструзия по его
   `zFrom..zTo` и с теми же фасками сверху/снизу. Геометрия резака повторяет форму реально напечатанной детали,
   поэтому деталь входит в гнездо с равномерным зазором, включая фаски.
3. Призрак строится от **собственной** формы верхнего листа, без учёта его собственных вырезаний более высокими
   элементами. Это гарантирует, что гнездо всегда ⊇ реальной детали (деталь можно подрезать сверху — гнездо
   останется достаточно большим).
4. `offset` выполняется с `JoinType.Round` и адаптивным числом сегментов, чтобы на выпуклых углах зазор
   не уменьшался.

## Последствия

- Пользователю понятно число: 0.15 мм на сторону — типичный допуск для FDM.
- Резак дешевле по операциям, чем полноценный 3D-меш с фасками: всё строится теми же функциями, что и деталь.
- Дырки внутри контура при `offset(+d)` **уменьшаются** (что физически верно: материал призрака «толстеет» -
  см. проверку в тестах M4).
- Слишком большой допуск визуально «раздувает» гнездо — в UI показываем предупреждение при `clearance > 0.6 мм`.

## Пример: фон и углублённый цилиндр

Две детали: фон (плита 100×100×2 мм, деталь A) и цилиндр Ø20 мм (деталь B), который в неё вставляется
и пересекается по Z.

- Допуск **цилиндра** (B) = 0.2 мм → гнездо в плите имеет радиус `10 + 0.2 = 10.2 мм`, то есть Ø20.4 мм;
  зазор по 0.2 мм с каждой стороны. Объём выреза: `π · 10.2² · h_перекрытия`.
- Допуск **фона** (A) на это гнездо не влияет вообще: A ничего не вырезает, он сам — материал.
  Значение допуска у A пригодится только там, где A сам врезается в деталь ниже.
- Проверено тестом `uses the clearance of the inserted (upper) element, not of the plate`:
  при допуске плиты 5 мм и допуске цилиндра 0.2 мм вырез остаётся равным `π · 10.2² · 2 мм³`.

Следствия для UI: подсказка у поля явно говорит «действует на гнёзда, которые этот элемент вырезает
в деталях НИЖЕ», а само значение показывается с бейджем «наследуется», если взято у группы или из проекта.

## Когда пересматривать

Если понадобится «посадка с натягом» (отрицательный допуск) — разрешить отрицательные значения, что автоматически
даст пересечение деталей.
