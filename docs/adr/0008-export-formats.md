# 0008. Экспорт: 3MF (мультиобъект, цвета) + бинарный STL; STEP вне MVP

- **Статус:** Accepted
- **Дата:** 2026-11-04

## Контекст

Пользователю нужен формат, пригодный для печати, желательно с несколькими деталями и цветами, и работающий
с Bambu Studio. Форматы-кандидаты: 3MF, STL, STEP, OBJ, AMF.

Ограничения: модель — меш из Manifold (`MeshGL`: `vertProperties` + `triVerts`), деталей несколько, у каждой
свой цвет из SVG, координаты исходные (раскладку делает слайсер).

## Рассмотренные варианты

1. **3MF** — OPC-архив (zip) с XML: единицы измерения, несколько объектов, базовые материалы/цвета, имена объектов,
   поддержка Bambu Studio/PrusaSlicer/Cura. Плюс: один файл на весь набор деталей.
   Минус: нужно писать архив и XML самим (нет зрелой лёгкой библиотеки в браузере).
2. **STL (binary)** — тривиальный писатель, 84 + 50·N байт. Минус: нет цветов, нет нескольких объектов
   стандартным способом, нет единиц.
3. **STEP** — CAD-обмен, требует B-Rep (OCCT), недоступен из меша без потери простоты.
4. **OBJ/AMF** — цвета есть у AMF, но поддержка слайсерами хуже, чем у 3MF.

## Решение

- **3MF — основной формат**: один файл, объект на деталь, `unit="millimeter"`, `basematerials` с цветами SVG,
  осмысленные имена объектов (`<name> (<id>)`). Zip собирается через `fflate` (`zipSync`, уровень 6, store для XML
  допустим, но deflate компактнее).
- **Бинарный STL — дополнительный**: экспорт выбранной детали или всех деталей, слитых в один меш; для быстрой
  проверки и для инструментов без 3MF.
- **STEP — вне MVP**: потребовал бы второго геометрического бэкенда (ADR-0002). Оставляем архитектурную возможность
  (см. `src/core/export`), но не реализуем.

Файлы 3MF: `[Content_Types].xml`, `_rels/.rels`, `3D/3dmodel.model`, при необходимости `3D/_rels/3dmodel.model.rels`.
Цвета передаются как `basematerials` с `displaycolor` (`#RRGGBBFF`), треугольники объектов ссылаются на материал.
Bambu Studio при импорте читает материалы как назначения филаментов — окончательный маппинг на AMS делает пользователь.

## Последствия

- Один 3MF = весь набор деталей: удобно для проверки и печати.
- Цвета «как в SVG» без ручной настройки.
- Никаких внешних зависимостей, кроме `fflate`.
- Обязательная ручная проверка: файл открывается в Bambu Studio без ошибок меша (критерий приёмки M6).

## Когда пересматривать

- Если Bambu Studio не примет базовые материалы → добавить запись `Metadata/model_settings.config`
  с явными назначениями экструдеров (проектный 3MF Bambu).
- Если появится требование STEP → добавить OCCT-экспорт как отдельный бэкенд.
