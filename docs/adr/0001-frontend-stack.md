# 0001. Стек фронтенда

- **Статус:** Accepted
- **Дата:** 2026-11-04

## Контекст

Нужно браузерное приложение: загрузка файла, дерево элементов с редактированием параметров, 2D- и 3D-предпросмотр,
экспорт файла. Геометрия тяжёлая (секунды CPU), UI интерактивный. Команда — один разработчик, важна скорость
разработки и предсказуемая экосистема для three.js.

## Рассмотренные варианты

1. **React 19 + TypeScript + Vite + Tailwind + zustand + three.js** — самый большой пул примеров и компонентов,
   простая ментальная модель для 3D-вьюпорта, zustand минимален и не диктует структуру.
2. **Vue 3 + Pinia** — короче шаблоны, но меньше готовых примеров вокруг three.js/геометрии.
3. **Svelte 5** — лучшая производительность, но меньше экосистемы и выше риск при нестандартных задачах.
4. **Vanilla TS + lit** — минимум зависимостей, но весь UI-каркас вручную, медленнее.

## Решение

React 19 + TypeScript (strict) + Vite + Tailwind CSS 4 + zustand + three.js.
Ядро (`src/core`) — чистый TypeScript без React, чтобы его можно было тестировать и переиспользовать
(CLI, воркер, будущий пакет). Связь «ядро ↔ UI» только через типы и функции, без React-контекста.

## Последствия

- Скорость разработки высокая, экосистема большая.
- Требуется дисциплина: геометрия и парсинг не должны протекать в компоненты.
- Состояние: zustand-сторы в `src/app/store`, настройки хранятся нормализованно по `nodeId`.
- Tailwind 4 подключается через `@tailwindcss/vite`, без `tailwind.config.js`.

## Когда пересматривать

Если понадобится SSR/деплой как библиотека или если размер бандла станет критичным.
