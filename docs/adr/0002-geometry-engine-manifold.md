# 0002. Геометрическое ядро — manifold-3d (WASM)

- **Статус:** Accepted
- **Дата:** 2026-11-04

## Контекст

Задача требует устойчивых операций, которых нет «из коробки» в three.js:

- 2D: объединение/вычитание контуров, **offset (смещение контура)** для допуска, разрешение `fill-rule`
  и самопересечений, площадь/bbox.
- 3D: булевы операции между экструзиями (гнёзда), проверка на замкнутость, объём.
- Всё это должно работать в браузере, быстро и на десятках фигур.

## Рассмотренные варианты

1. **manifold-3d (WASM)** — быстрые и численно устойчивые булевы операции, есть `CrossSection` с `offset`,
   `fillRule`, `extrude`, `hull`; компактная WASM-сборка; меши по построению замкнуты и manifold.
2. **three-bvh-csg / three-csg-ts** — завязано на three.js, булевы операции менее устойчивы, нет 2D-offset.
3. **Replicad / OpenCascade (OCCT) WASM** — есть нативные `chamfer`/`fillet` и экспорт STEP, идеальная точность,
   но 10+ МБ WASM, заметно медленнее, сложнее API и тяжёлая интеграция для браузера.
4. **clipper2-js + собственные булевы в 3D** — 2D закрывает, 3D булевы пришлось бы писать самим.

## Решение

Manifold как единственный движок твёрдого тела. Все 2D-операции — через `CrossSection`
(`ofPolygons` с `fillRule`, `offset`, `subtract`, `add`, `intersect`, `extrude`), все 3D — через `Manifold`
(`subtract`, `add`, `intersect`, `volume`, `getMesh`).

Экспорт STEP, для которого нужен OCCT, из MVP исключён (см. ADR-0008).
Фаска реализуется поверх Manifold (см. ADR-0007), нативного fillet/chamfer у него нет.

## Последствия

- Скорость: булевы операции — миллисекунды, полный пересчёт модели укладывается в интерактив.
- Гарантия пригодности к печати: результат Manifold по построению замкнут (нет дырок в меше).
- Нет STEP и нет «CAD-точной» фаски — это осознанная плата за скорость и размер.
- Модуль обязан жить в Web Worker (ADR-0010): WASM инициализируется асинхронно, вычисления блокирующие.
- Код ядра обращается к движку только через `src/core/geometry/*`, чтобы бэкенд можно было заменить
  (например, добавить OCCT-путь для STEP) без переписывания солвера.

## Когда пересматривать

- Если STEP станет обязательным → добавить второй бэкенд (`occt`) за тем же интерфейсом.
- Если понадобится CAD-точная фаска/скругление → рассмотреть OCCT только для этих операций.
