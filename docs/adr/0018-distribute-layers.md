# 0018. Инструмент «Разложить по слоям»: элемент встаёт на накрывающий его слой

- **Статус:** Accepted
- **Дата:** 2026-11-04

## Контекст

Инструмент несколько раз менял правило:

1. по индексу (шаг 1.5 мм, толщина 2 мм) — детали не врезались друг в друга, гнёзд не было;
2. «самый низкий перекрытый слой» — логотип HTML5 схлопывался в одну плоскость;
3. «строгая лестница по порядку отрисовки» — на пейзаже поднималось всё подряд: холм вставал на
   солнце, кроны — на ствол, хотя геометрически они друг друга не поддерживают.

Нужно правило, которое читает картинку так же, как человек: элемент стоит на том, что его **накрывает**.

## Решение

Инструмент живёт в меню **«Инструменты»** (иконка «ключ и молоток») в заголовке панели слоёв.

Раскладка (`src/core/solver/distribute.ts`), детали обходятся в порядке отрисовки (снизу вверх):

1. **Накрытие важнее пересечения.** Опора — самая верхняя из уже поставленных деталей, чей габарит
   **целиком содержит** габарит текущей (`boxContains`). Элемент, лежащий внутри другого, встаёт на него.
2. Если ничего не накрывает, но что-то **пересекает** — опора самая высокая из пересечённых (две
   пересекающиеся планки встают друг на друга).
3. Если нет ни того, ни другого — элемент остаётся на базовом слое (`defaultZFrom`): непересекающиеся
   элементы не строятся друг над другом.
4. `zFrom` = верх опоры − `SINK_MM` (1 мм), `zTo` = `zFrom` + `LAYER_MM` (5 мм). Заход в 1 мм даёт гнездо
   (ADR-0005).

## Что получается на `landscape.svg`

| элемент | диапазон | почему |
| --- | --- | --- |
| sky | 0–5 | база, под ним ничего |
| sun | 4–9 | накрыт только небом |
| hill | 4–9 | накрыт только небом → та же высота, что у солнца |
| trunk | 8–13 | целиком внутри холма → встаёт на холм |
| crown | 4–9 | торчит выше холма, накрывает его только небо |
| crown-2 | 4–9 | то же |

Логотип HTML5: его фигуры перекрываются по краям, но не накрывают друг друга, поэтому получается
база 0–5 и общий слой 4–9 — это следствие правила, а не ошибка.

## Последствия

- «Ступеньки» появляются только там, где элемент действительно лежит на другом (ствол на холме, вложенные
  фигуры в логотипах), а не по порядку в документе.
- Накрытие считается по габаритам поддерева в пользовательских единицах: группы работают так же, как фигуры.
- Константы `LAYER_MM`/`SINK_MM` вынесены, их же показывает подсказка пункта меню.
- Группы-контейнеры не трогаются: диапазоны назначаются только печатным деталям (`findPartRoots`).
