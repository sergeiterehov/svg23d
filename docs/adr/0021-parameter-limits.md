# 0021. Границы параметров и «нулевая» высота

- **Статус:** Accepted
- **Дата:** 2026-11-04

## Контекст

Значения приходили из трёх мест (поля инспектора, дельты `+2`/`-2`, стрелки на модели) и нигде не
проверялись: «до» можно было поставить ниже «от», допуск — 100 мм, фаску — больше высоты детали.
Первое ломало модель (элемент пропадал), остальное давало мусор в геометрии.

## Решение

Границы живут в `src/core/model/limits.ts` и применяются **в сторе** (`updateSettings`,
`updateSettingsBatch`, `updateGlobal`), поэтому любая точка ввода получает уже корректное значение:

| Параметр | Ограничение |
| --- | --- |
| «Высота от» | не больше «до» (разница может быть нулевой) |
| «Высота до» | не меньше «от» |
| Допуск | 0…10 мм |
| Фаски | 0…`высота полосы − противоположная фаска` |
| Размер модели | 1…1000 мм |

- **Минимальная разница высот — 0.** «До» может совпасть с «от»; такой элемент просто не печатается:
  `resolveLeaves` его пропускает с информационным предупреждением, `buildModel` дополнительно
  отбрасывает полосы нулевой толщины (защита от вырожденного экструда).
- Правка «от» или «до» подтягивает только редактируемое поле: если «от» упирается в потолок, оно
  останавливается на «до», а не тянет «до» за собой. Если в патче пришли оба конца, «до» следует за «от».
- Фаски связаны попарно: увеличение верхней упирается в высоту минус нижняя.
- Числовое поле принимает `min`/`max` и обрезает как абсолютные значения, так и результат дельты.

## Последствия

- Предупреждение о том, что элемент не напечатан, теперь информативное: показывает значения
  («до» (0) не больше «от» (0)).
- Красная подсказка в инспекторе появляется только при реальной инверсии (`до < от`), а не при нулевой
  толщине.
- Стрелки высоты упираются в те же границы: тянуть «до» ниже «от» или «от» выше «до» больше нельзя.
- Тесты: `tests/limits.test.ts` (9 проверок на пары высот, допуск, фаски, размер).
