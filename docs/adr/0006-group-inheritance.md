# 0006. Группы `<g>`: объединение детей и наследование настроек

- **Статус:** Accepted
- **Дата:** 2026-11-04

## Контекст

SVG из векторного редактора содержит иерархию `<g>`. Пользователь ожидает:
дерево в приложении повторяет дерево документа (не плоский список), настройки можно задать как группе, так и
отдельному элементу. Возникает вопрос: что означает z-диапазон или фаска, заданные на группе, и что происходит с
пересечениями детей внутри группы.

## Рассмотренные варианты

1. **Группа — только контейнер настроек по умолчанию**, дети наследуют, но могут переопределить.
   Геометрия считается на листьях. Просто, предсказуемо, легко объяснить в UI.
2. **Группа — самостоятельная геометрическая сущность**: union детей как единое тело со своим z-диапазоном,
   фаской и вырезанием. Мощнее, но: что делать, если у детей свои z-диапазоны? Нужны правила разрешения
   конфликтов, «clipping» детей по диапазону группы, пересчёт фаски на union — существенно сложнее.
3. **Группа вообще не имеет настроек**, параметры только на листьях. Проще всего, но пользователю придётся
   редактировать десятки элементов вручную.

## Решение

Вариант 1 в комбинации с объединением:

- У группы есть собственные `zFrom/zTo/clearance/chamferTop/chamferBottom/isPart`, которые действуют как
  **значения по умолчанию** для потомков.
- Разрешение параметра для листа: ближайшее явно заданное значение по цепочке предков, иначе значение из `global`.
  В UI бейдж «наследуется» (показывает источник) / «переопределено».
- Геометрически группа не создаёт отдельного тела: тело детали = union листьев. Вырезание и фаски считаются
  на листьях. Это гарантирует отсутствие «швов» и внутренних полостей внутри детали.

Следствие: фаска на группе применяется к каждому листу отдельно. Если нужна фаска на объединённый силуэт,
это осознанное ограничение MVP (см. «Когда пересматривать»).

## Последствия

- UI простой: одна и та же панель для группы и листа, разница — бейдж наследования.
- Нет сложных конфликтов «группа 0..2, ребёнок 3..5».
- Пользователь может задать высоты всей группе одним действием — основной сценарий («всё дерево 2..4 мм»).
- Ограничение: фаска на группу не «сглаживает» стыки между детьми группы.

## Когда пересматривать

Если понадобится фаска на объединённый силуэт группы (или «группа как единое тело с обрезкой по диапазону») —
ввести у группы флаг `geometryMode: 'union-body'` с явным пересчётом и предупреждением о стоимости.
