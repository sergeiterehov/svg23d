# 0009. Единицы и система координат

- **Статус:** Accepted
- **Дата:** 2026-11-04

## Контекст

SVG живёт в «пользовательских единицах» с осью Y вниз. Печать живёт в миллиметрах с осью Z вверх.
Пользователю нужен предсказуемый способ задать размер модели: «хочу ширину 120 мм».

## Рассмотренные варианты

1. **Fit по стороне**: пользователь задаёт ширину (или высоту) модели в мм, масштаб считается из `viewBox`.
   Естественно для печати, не требует думать о единицах редактора.
2. **Коэффициент масштаба** к единицам SVG — требует знать, в чём рисовали.
3. **Доверять `width`/`height` в SVG** — часто отсутствуют или заданы в `px`/`%`, ненадёжно.

## Решение

- Внутренние координаты ядра — **миллиметры**, Z вверх, XY — плоскость печати.
- Масштаб считается по **bbox содержимого** (объединение bbox всех фигур), а не по `viewBox`:
  `scale = fitSizeMm / contentWidth` (или по высоте, если выбрана высота). Причина: пользователь
  ожидает, что «ширина 120 мм» — это ширина *изделия*, а не пустого поля вокруг картинки
  (в `sample.svg` содержимое занимает ~70% `viewBox`). Операнд `viewBox` остаётся областью просмотра в 2D.
  Опция `fit: 'width' | 'height'`, значение в мм, пропорции всегда сохраняются.
- Если у SVG есть `width`/`height` в абсолютных единицах (`mm`, `cm`, `in`, `pt`, `px`@96dpi) — показываем
  предполагаемый размер как ориентир (`declaredSizeMm`), но пользователь всегда может переопределить.
- Ось Y инвертируется, начало координат — левый нижний угол содержимого: все X/Y ≥ 0, нижняя плоскость
  `z = 0` — удобно для слайсеров.
- Числа в UI — мм с шагом 0.1; в ядре округление не применяется до экспорта.

## Последствия

- Все параметры (высоты, допуск, фаски) — в мм, размерности согласованы.
- Пользователь всегда видит фактический размер модели (ширина × высота × полная высота) в панели статистики.
- Плоские элементы с `zTo <= zFrom` отбрасываются с предупреждением.
- Инверсия Y выполняется один раз при импорте (в `units.ts`), дальше весь конвейер работает в «правильной» СК.

## Когда пересматривать

Если понадобится экспорт в дюймах или привязка к физическому размеру SVG без пересчёта — добавить выбор единиц.
